Capabilities

Multi-modal detection pipeline

YOLOv8 Object Detection

Fine-tuned on MIDV-2020 to detect documents, faces, signatures, and text fields with class-specific confidence thresholds.

Haar Cascade Plates

OpenCV Haar cascade for license plate detection. Covers a wide range of plate formats across IN, US, and EU regions.

EasyOCR + PII Regex

Text detection with smart filtering — only text matching PII patterns (Aadhaar, PAN, passport, email, IP, date, MRZ) is erased.

Smart Mask Engineering

Overlapping box merging, proportional adaptive expansion, rounded rectangle masks, and OCR internal gap filling.

Per-Region Inpainting

Each masked region is inpainted individually — Telea structure recovery then two passes of LaMa neural inpainting at full resolution.

Live Mask Statistics

Region count, total masked area percentage, and per-region size stats are logged on every inference run.

Pipeline

How redaction works

01

Upload Image

Your image is processed entirely locally — no data is sent to any external server.

02

Detection

YOLOv8 + Haar cascade locate objects. EasyOCR reads all visible text.

03

PII Filtering

Regex engine classifies text. Only PII-matching strings are flagged for erasure.

04

Smart Masking

Boxes merged, proportionally expanded, drawn as rounded rectangles. Gaps filled.

05

Neural Inpainting

Telea pre-fill → LaMa pass 1 → LaMa pass 2. Each region processed independently.
