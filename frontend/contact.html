About This Project

VoidBox

A multi-modal PII detection and redaction engine built from scratch. Evolved from a basic face-blur tool into a production-grade privacy pipeline with object detection, OCR, regex classification, smart masking, and neural inpainting.

YOLOv8 EasyOCR LaMa OpenCV Flask PyTorch
Current Stage Stage 9: Robust Mask Engineering
Detection Layers YOLO + Haar + EasyOCR + Regex
Inpainting Telea → LaMa × 2 (per-region)
Privacy 100% local — no data leaves
